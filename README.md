# HOTEL RESERVAS(full stack)

Este projeto é um sistema que organiza as reservas e quartos de um estabelicimento
(a tabela de reservas esta em parte branca por causa do contato direto mas manualmente é possivel preencher)


# Funcionalidades

Editar quarto

Excluir quarto

Listar quarto

Buscar quarto

Criar quarto

Listar reserva

Editar reserva

Buscar reserva

Excluir reserva

Criar reservas

# Tecnologias

JavaScript

HTML

CSS

Node

Prisma

# Como usar

Clone o repositório: git clone e o url da pasta
Rode no terminal do vscode o backend: cd backend npm install npm run dev
Abre o site pelo index e o backend teste no insomia
